Side Note

A simple way to notice when someone's eyes wander during an online exam — using the webcam they already have.

Works in the browser · No extra hardware

Why we built this

During online exams, it's hard to tell if someone is glancing at their phone, notes on their desk, or a second screen. Proctors can't watch every student closely.

Side Note uses eye tracking to gently flag when attention drifts away from the screen — no special equipment, just a regular webcam.

What it does

Side Note follows where someone is looking — on the exam content, toward the bottom of the screen, or off to the sides — and logs brief warnings when it looks suspicious.

Real-time tracking

Follows gaze as the student works through questions, with a live status panel during the exam.

No extra gear

Runs on any laptop with a built-in webcam. Nothing to install or ship to students.

How it works

Web demo: WebGazer.js runs in the browser. After a quick 9-point calibration, it maps eye movement to screen coordinates and flags off-screen glances.

Desktop app: OpenCV and MediaPipe track iris position and hand placement locally for deeper analysis — run with python main.py.

Built with

Python OpenCV MediaPipe WebGazer.js FastAPI

Get started

Run the backend with python run_server.py, then open the demo at localhost:8000/demo.html.
