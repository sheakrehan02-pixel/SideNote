What is Side Note?

Side Note is a real-time eye tracking application that works with your existing webcam. No special hardware, no subscriptions — just run it and start tracking gaze direction, iris position, and visual attention.

Built for accessibility research, UX testing, and anyone who wants to understand where users look.

How it works

Desktop (Python): Uses OpenCV + MediaPipe Face Mesh to detect 468 facial landmarks. Iris and eye centers are used to compute gaze direction. A green box confirms when eyes are tracked.

Web prototype: WebGazer.js runs in the browser. Calibrate once, then gaze coordinates are mapped to the screen for testing without installation.

Tech stack

Python OpenCV MediaPipe WebGazer.js NumPy
